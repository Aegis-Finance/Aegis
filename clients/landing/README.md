# Aegis landing (`aegisprotocol.org`)

Static marketing site — no wallet, no ZK bundles. Deploy on **Cloudflare Pages** project `aegis-landing`.

```bash
npm ci
npm run dev      # http://localhost:5173
npm run build    # dist/
```

Custom domains: `aegisprotocol.org`, `www` → apex redirect (301).

See `docs/ops/frontends_clouadflare.md`.
