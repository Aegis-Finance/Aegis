# Aegis Token Sale

Focused client for the on-chain **Dutch auction** (`AutomatedDutchAuction`) during the TGE window on **Sonic**.

Minimal surface: live auction metrics, Sonic Gateway bridge tab, public and ZK purchase paths where the verifier is wired.
