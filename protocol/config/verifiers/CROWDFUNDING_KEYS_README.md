# Crowdfunding Circuit Verification Keys

## ⚠️ IMPORTANT: These files need to be generated from your trusted setup ceremony

The `*.verifying_key.json` files for `crowdfunding`, `milestone`, and `refund` circuits must be generated by:

1. **Compiling the circuits:**
   ```bash
   cd circuits
   circom crowdfunding.circom --r1cs --wasm
   circom milestone.circom --r1cs --wasm
   circom refund.circom --r1cs --wasm
   ```

2. **Running trusted setup ceremony:**
   ```bash
   snarkjs powersoftau new bn128 14 pot14_0000.ptau -v
   # ... continue with ceremony ...
   snarkjs zkey new crowdfunding.r1cs pot14_final.ptau crowdfunding_0000.zkey
   # ... continue with ceremony contributions ...
   snarkjs zkey export verificationkey crowdfunding_final.zkey crowdfunding.verification_key.json
   ```

3. **Copy the generated files:**
   - `crowdfunding.verification_key.json` → `config/verifiers/crowdfunding.verifying_key.json`
   - `milestone.verification_key.json` → `config/verifiers/milestone.verifying_key.json`
   - `refund.verification_key.json` → `config/verifiers/refund.verifying_key.json`
