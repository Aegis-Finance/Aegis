# Architecture diagrams

Rendered views of the Aegis protocol on Sonic. Each name below is a **PNG** (overview) and **SVG** (scalable) pair in this folder.

| Diagram | What it shows |
|---------|----------------|
| `system_overview` | Major modules and how they fit together |
| `contract_interactions` | Core contract call relationships |
| `contracts_surface` | Layout of the `contracts/` tree |
| `client_flow` | Apps, wallets, and chain entry |
| `data_flow` | ZK, governance, and liquidity data paths |
| `security_architecture` | Threats and mitigations |
| `zk_circuit_architecture` | Circom circuits and on-chain verifiers |

Source code and tests are in [`../contracts/`](../contracts/).
